# 持仓全景图

在你自己电脑上看美股持仓和实时报价。这不是网页文件，也不能把对话里的 `127.0.0.1` 复制到浏览器——那个地址在我这边的机器上，你电脑打不开。

## 在你电脑上打开

先装 [Node.js 20+](https://nodejs.org/)，再在项目目录里执行：

```bash
npm install
npm run preview
```

等终端出现 `Ready` 后，用浏览器打开：

**http://localhost:43147**

`npm run preview` 会先编译再启动，第一次要等一会儿，之后就快了。

只在 Cursor 对话里看：点预览卡片，不要自己输入 IP。

## 之后怎么改持仓

直接跟我说即可：

- `买入 AAPL 10 股，成本 180`
- `卖出 NVDA 2 股`
- `现金 3578.32 美元`
- `提现 8000 人民币，汇率 7.05`

我会改 `data/portfolio.json`。你本机重新拉代码后再 `npm run preview`，数字就对上了。

净资产 = 股票市值 + 现金。  
账户收益率 =（净资产 − 净投入）÷ 净投入。  
今年收益率 =（净资产 − 年初 $52,418 − 今年入金 + 今年提现）÷ $52,418。

## 说明

- 报价来自 Yahoo Finance，不用 API Key。
- 涨跌按 A 股习惯：**红涨绿跌**。
- 数据只存在你电脑上的 `data/portfolio.json`，不上公网。
