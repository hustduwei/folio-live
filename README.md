# 持仓全景图

本地实时跟踪美股报价和持仓总市值。页面按板块画出仓位地图，报价每 3 秒刷新。

这不是一个可以双击打开的 HTML 文件。它是 Next.js 应用，必须先在本机启动开发服务器。

之后你只要说「买入 / 卖出」即可，例如：

- `买入 AAPL 10 股，成本 180`
- `卖出 NVDA 2 股`

我会改 `data/portfolio.json`，本地页面会自动跟上。

## 为什么本机打不开

云端预览里的地址（例如 `http://127.0.0.1:43147`）跑在我这边的机器上，不是你电脑上的 localhost。你在自己浏览器里输入这个地址，当然打不开。

要在自己电脑上看：

```bash
npm install
npm run dev
```

然后打开 [http://localhost:43147](http://localhost:43147)。

在 Cursor 的 Cloud Agent 对话里，点预览卡片即可，不用自己装。

## 说明

- 报价来自 Yahoo Finance，无需 API Key。盘中接近实时，盘前盘后用全日最新价。
- 美股收盘后数字不会跳，但页面仍会持续刷新；开盘后会跟着变。
- 涨跌颜色按 A 股习惯：**红涨绿跌**。
- 持仓保存在 `data/portfolio.json`，没有登录，也不绑定 IP。
- 股票会按科技 / 消费 / 金融等板块自动归类，用来画持仓地图。
